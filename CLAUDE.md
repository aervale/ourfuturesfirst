# Our Futures First

Two people (David and April) and their Claude sessions work on this repo at the same time.

- Before starting, `git fetch && git rebase origin/main`, then read `shared-context.md`.
- When you make a decision, find a pitfall, change how live is changed, or leave a question open, update
  `shared-context.md` in the same commit, and push soon after so the other session sees it.
- This repository is public. Never commit emails, tokens, passwords or anything private.
